## Perilaku

- **Peta gagal tersimpan:** pause menu: "Peta dunia tidak bisa disimpan… dimuat ulang akan mendapat dunia berbeda"; titik merah di tombol menu; badge planet "Not saved"/"Belum tersimpan" dengan tooltip. Kegagalan di konstruktor (dunia pertama) juga terlihat karena status dibaca saat menu dibuat. Status kembali normal begitu penulisan berikutnya berhasil.
- **Misi/tips:** mengganti dunia (Rebuild/Shuffle) mengganti daftar misi ke milik dunia baru; kembali ke seed lama mengembalikan progresnya. Reset misi hanya untuk dunia aktif. Kegagalan simpan misi/tips masuk status "error" yang sama.
- **Konfirmasi regenerate:** pesan menyebut seed lama dan jumlah ruangan, rumah, kampanye Trade, langkah misi yang tetap tersimpan di bawah seed itu, serta cara kembali (bangun ulang seed itu). Berlaku untuk "Rebuild world" dan "Shuffle world".

## Catatan jujur

- **Urutan kerja:** untuk E2 saya menulis implementasi sebelum test (tidak "gagal dulu" seperti E1). Test tetap menangkap satu bug nyata di kode saya: field `this.progress` di `Missions` menimpa method `progress()`; sudah diganti nama menjadi `this.store`. Test tidak dijalankan terhadap kode lama untuk memperlihatkan gagal satu per satu.
- **Tidak ada verifikasi browser:** konfirmasi dua tekan, badge, toast, dan titik merah belum dilihat langsung. `menuController` dan DOM menu jeda tidak punya test; yang diuji adalah logika murninya (`TwoStepConfirm`, `saveStatus`, `worldImpact`, `ScopedProgress`, `World`). Perlu masuk QA browser AGY.
- **Tips `intro`:** kartu intro ikut per dunia (bagian dari tips), jadi dunia baru memunculkan kartu pembuka lagi. Dunia pertama mengadopsi status lama sehingga pemain lama tidak melihatnya ulang. Bila ingin intro sekali per perangkat, perlu key terpisah. Keputusan produk untuk lead.
- **Key lama dibiarkan:** `planet_globe_missions` dan `planet_globe_tips` tidak dihapus supaya build lama tetap menemukannya. Mereka tidak lagi diperbarui.
- **Tombol "hapus peta"** di sidebar planet (`clearStorageBtn`) tetap menghapus tanpa konfirmasi dan tidak disentuh.
- **Batas pada `worldId`:** `worldId = world:<seed>:grid:<subdivision>` mengabaikan slider laut/gunung. Kembali ke seed lama dengan slider berbeda memberi peta berbeda dengan state yang sama. Tidak diubah di sini; layak jadi catatan G-04 lanjutan.
- **Ukuran entri IndexedDB per dunia** belum diukur (bagian G-04 yang butuh V-07).

## Risiko

1. `setInterval(syncAlert, 2000)` di `PauseMenu` berjalan seumur halaman. Murah (satu pembacaan status + toggle class), tetapi tidak pernah dibersihkan karena `PauseMenu` singleton.
2. Ukuran peta di `localStorage` (kuota ~5 MB bersama key lain) belum diukur; kegagalan kini terlihat, tetapi penyebab kuota tidak ditangani.
3. Migrasi satu arah: build lama yang dibuka setelah build ini menulis ke key global lagi, dan tidak akan diadopsi ulang (marker sudah ada).
4. Dunia yang dibuat sebelum build ini dan belum pernah membuka misi akan mengadopsi key global lama hanya jika key itu ada; dunia tanpa key lama mulai kosong (benar).
